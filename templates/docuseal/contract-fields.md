# DocuSeal Contract Template & Field Mapping

This document specifies the field mappings and template configuration for DocuSeal e-signature generation in **WF-01**.

---

## 1. DocuSeal Template Configuration

* **Template Name**: `Consulting Services Master Agreement`
* **Template Type**: Reusable template with pre-placed signing fields and pre-filled merge text fields.
* **Signer Roles**:
  * `Client` (Signer 1): First signer; receives email invite directly from DocuSeal upon submission.
  * `Consultant` (Signer 2 / Pre-signed): Either pre-signed inside the template or auto-countersigned.

---

## 2. Field Mapping Table

The following table maps canonical database fields from the `clients` record to DocuSeal template fields:

| Database Field (`clients`) | DocuSeal Field Name | Field Type | Role | Purpose / Notes |
| :--- | :--- | :--- | :--- | :--- |
| `name` | `Client Contact Name` | Text (pre-filled) | Client | Full legal name of client signee |
| `email` | `Client Email` | Email (submitter) | Client | Destination email address for signing invite |
| `company` | `Client Company Name` | Text (pre-filled) | Client | Entity name entering into contract |
| `services` | `Scope of Services` | Textarea (pre-filled) | Consultant | Bulleted scope of work defined by owner |
| `price` | `Contract Value` | Text (pre-filled) | Consultant | Numeric fee (e.g. `5000` or `5,000.00`) |
| `currency` | `Currency` | Text (pre-filled) | Consultant | ISO currency code (`USD`, `EUR`, `GBP`, `CZK`) |
| `payment_terms` | `Payment Terms` | Text (pre-filled) | Consultant | Schedule (e.g. `50% upfront, 50% upon delivery`) |
| *(Generated by DocuSeal)* | `Client Signature` | Signature | Client | Interactive e-signature box |
| *(Generated by DocuSeal)* | `Signature Date` | Date | Client | Auto-populated timestamp of signature |

## 3. DocuSeal API Submission Payload

When **WF-01** triggers, it executes an HTTP POST request to the DocuSeal REST API using the bearer token / `X-Auth-Token`.

### Endpoint
```http
POST https://api.docuseal.com/submissions
Header X-Auth-Token: {{$env.DOCUSEAL_API_KEY}}
Content-Type: application/json
```

### Request Payload Example

```json
{
  "template_id": 120491,
  "send_email": true,
  "order": "preserved",
  "submitters": [
    {
      "role": "Client",
      "email": "jane@example.com",
      "name": "Jane Doe",
      "fields": [
        {
          "name": "Client Company Name",
          "default_value": "Acme Innovations Inc."
        },
        {
          "name": "Scope of Services",
          "default_value": "- End-to-end CRM integration\n- Custom reporting pipeline\n- Deployment and documentation"
        },
        {
          "name": "Contract Value",
          "default_value": "6,500.00"
        },
        {
          "name": "Currency",
          "default_value": "USD"
        },
        {
          "name": "Payment Terms",
          "default_value": "50% upfront deposit upon contract signing, 50% upon final delivery."
        }
      ]
    }
  ]
}
```

## 4. Response Extraction & Database Storage

DocuSeal returns a JSON response containing the submission object.

```json
{
  "id": 984512,
  "slug": "sub_984512_xyz",
  "status": "pending",
  "audit_log_url": null,
  "submitters": [
    {
      "id": 150241,
      "slug": "sig_150241_abc",
      "email": "jane@example.com",
      "status": "sent"
    }
  ],
  "created_at": "2026-10-29T10:00:00Z"
}
```

### Values Extracted by WF-01:
* `id` $\rightarrow$ stored into `clients.docuseal_submission_id`
* Status is updated in database: `clients.status = "contract_sent"`
